# 차량 터치 UI · v0.13

## 방향

- 제품: 나와 가족을 위한 차량 응급지원
- 인상: 차분하고, 큼직하고, 명확하게
- 환경: 손을 뻗어 조작하는 차량 화면
- 핵심 장면: 네 개의 큰 홈 버튼과 간결한 연결 화면
- 일관된 표시: 119 빨강, 112 파랑, 버튼 글씨 중앙 정렬

요청한 [unslop](https://github.com/heydamir/unslop)의 점검·수정 순서를 적용했다. 사용자가 버튼 확대와 문구 축소를 명시적으로 요청한 범위에서 화면 구성을 바꿨다. 웹 랜딩 페이지의 작은 컨트롤·장식·히어로 이미지는 차량 앱에 적용하지 않았다.

## 관찰과 조치

| 기존 v0.12에서 관찰한 점 | v0.13 반영 |
|---|---|
| 홈의 112·안심콜은 64dp, 119·상담은 160dp로 차이가 큼 | 홈 네 버튼을 같은 크기로 배치. 가용 높이에 따라 144~300dp, 좁은 화면은 160dp |
| 버튼은 작고 3개의 소개·안내 문구가 큰 공간을 차지함 | ‘나와 가족의 안전’ 제목 하나와 짧은 버튼 이름으로 축소 |
| 넓은 화면에서도 본문 폭이 1200dp로 제한됨 | 최대 1600dp로 확대 |
| 일반 버튼 64dp·22sp, 설정 컨트롤도 작음 | 일반 버튼 최소 96×96dp·28sp. 탐색 24sp, 체크·선택·입력 영역도 확대 |
| 긴 연결 화면에서 핵심 조작을 찾으려면 아래로 내려야 함 | 연결 화면은 영상·정보·추가 지원·종료를 우선 표시 |
| 주행 긴급 흐름의 역할 조작과 설명이 기본 화면을 채움 | ‘상황·정보 전달’에서 기존 전달·동의·철회·안전 확인·인계를 진행 |
| 내부 접수 식별번호가 기본 연결 화면에 노출됨 | 추가 지원·상황 전달의 상세 화면으로 이동 |
| 긴 메뉴와 여러 문장의 버튼 이름 | 설정·추가 지원을 2열로 묶고 레이블을 줄임 |
| 매뉴얼에 관련 없는 차량 상태 조절 패널이 선행함 | 매뉴얼에서 해당 패널을 제외하고 주제 6개를 2열로 배치. 원문 단계·주의·출처는 보존 |
| 숫자와 한글의 글자 크기 차이로 카드 기준선이 어긋남 | 행의 기준선 정렬을 끄고 같은 행의 높이를 맞춤 |

Google의 차량용 [크기 지침](https://developers.google.com/cars/design/automotive-os/design-system/sizing)은 최소 76×76dp 터치 영역을 안내한다. 이번 앱의 일반 조작은 96dp 이상으로 잡았으며, [시각 원칙](https://developers.google.com/cars/design/design-foundations/visual-principles)을 참고해 인접 조작의 간격을 24dp로 맞췄다. 이 수치는 실차 적합성 인증이나 운전 중 사용 안전성의 증명은 아니다.

## 아홉 단계 적용

1. 간격: 버튼 사이 24dp, 공통 4dp 눈금, 본문 폭 확대
2. 색: 기존 밝은 배경·흰 표면 유지, 119 빨강·112 파랑 유지
3. 아이콘: 의미 없는 장식·새 아이콘 없음
4. 문구: 홈·연결의 반복 안내 축소, 상세 설명은 해당 기능 화면으로 이동
5. 글씨: 버튼 28sp, 탐색 24sp, 홈의 주요 숫자는 최대 64sp, 400·500 굵기
6. 배치: 보통 가로 화면은 2×2, 높이가 짧은 가로 화면은 네 버튼을 한 줄로 배치. 좁은 화면은 세로 배치
7. 세부: 최소 터치 영역, 중앙 정렬, 행 정렬, 누름·포커스·비활성 상태 유지
8. 시각 자료: 실제 Android 앱 화면 사용, 앱을 HTML로 재현하지 않음
9. 움직임: 기존 100~120ms 상태 전환 유지, 추가 진입·반복 애니메이션 없음

## 범위와 한계

- 개선 전후 모두 동일한 표준 Android 34 검증용 AVD에서 확인한다. Pleos AVD에서 앞서 발생한 차량 오디오 서비스 오류는 이번 UI 작업에서 수정하지 않았다. 실제 CarUX 콜백·Pleos 차량 SDK·실차 검증은 남아 있다.
- 모든 기관 연결·영상·위치는 기존 모의 기능이다. 실제 발신·출동·촬영·새 외부 API를 추가하지 않았다. `시연 모드 | 실제 신고·상담 연결 아님` 공통 안내를 유지한다.
- 실제 플랫폼 제한은 그대로 적용된다. 새 상세 화면도 실제 상세 조작 제한 대상이다. 정차·PIN을 긴급 요청의 선행 조건으로 추가하지 않았다.
- 의료정보 인증·암호화·동의·철회·화면 보호를 유지한다. 검증 중 PIN을 입력·설정하거나 건강정보를 생성·삭제하지 않으며 보호 화면을 캡처하지 않는다.
- 개인정보 입력 폼의 공통 크기·글씨는 수정했지만, 기존 개인 PIN을 통과해 의료정보 전체 화면을 시각 검사한 것은 아니다. 사람의 실제 손 조작·TalkBack·로터리·차량 진동·시청 거리 검증은 포함하지 않는다.
- 이전 APK, 기존 AVD와 등록 정보, 원래 소스와 화면 캡처를 보존한다. 이번 변경은 로컬 작업이며 GitHub 업로드를 뜻하지 않는다.
