## 시작 전 의료정보 잠금

가족정보를 처음 열 때 차량 Android의 PIN·패턴·비밀번호 인증을 사용한다. 시스템 인증이 없으면 발표자가 앱 PIN 6~12자리를 두 번 입력해 직접 설정한다. 고정 기본 PIN은 없다. PIN을 발표 화면·녹화·채팅에 남기지 않는다. 실제 의료정보는 입력하지 않고 가상 예시만 쓴다.

가족·의료정보 화면은 캡처/화면 공유가 제한된다. 발표 때는 공개 홈·연결 상태·협력 화면을 공유하고, 보호 화면은 현장 장치에서 직접 확인한다. 홈 복귀·앱 전환·60초 경과 후에는 다시 인증한다. 이 잠금은 긴급 연결의 선행 조건이 아니다.

## 기능별 추가 시연

- S01: 인증 후 합성 영상 요청 → 동의 → 시작 → 장면 변경 → 중단. 전방·후방·스마트폰 소스를 구분한다.
- S05: 상담 전달 요약 → 가상 관찰/혈당 수정 → 검토 동의 → 상황실 확인. 진단·위험도 판정은 하지 않는다.
- S14/E02: 경찰 요청 → 검토 → 거절/재요청/가상 승인. 상황실 전문가 안내 → 위치 동의 → 만남 장소 제안 → 사용자 확인 → 모의 설정.
- S01/E04: 안심콜 등록/미등록 예시, 별도 조회 동의. 운전자 선택은 환자 선택과 독립적이다.
- S08~S12: 문자/의사표현/음성 도움말 모형/승하차 도움/쉬운 안내. 큰 글씨와 520dp 좁은 화면도 도구에서 선택한다.
- 협력 실험: 구급대가 빠른 대조 조건, 참여 차량 없음, 초대 거절, 표시 거절·철회, 앱 전환 시 미리보기 중단과 명시적 재시작.
- 더보기 → 설정·시연 도구 → 기본 응급 매뉴얼. 공개 안내이므로 의료정보 인증 없이 접근한다.

18개 S01~S14/E01~E04의 기관·목적·기본 행동은 [기능 매트릭스](FEATURE_MATRIX.md)를 따른다.

## 차량 없는 주행 상태 검증

`Start-Virtual-Console.cmd`로 공식 콘솔을 연다. 전용 Pleos 에뮬레이터에서 P/0 → D/가상 속도 → P/0을 바꾸면 실제 CarUxRestrictions 콜백을 받는다. 제한 중에는 상세 입력·영상·긴 목록을 제한하며 수동 이동 상태나 PIN으로 해제하지 않는다. 검사가 끝나면 P/0으로 복귀한다. 자동 재현은 `python scripts/smoke-driving.py`다. 실차·도로 시험을 의미하지 않는다.

## 실행과 종료

새 APK는 `artifacts/LifeLink119-v0.6.0-demo-debug.apk`. PC 보조 화면은 `http://127.0.0.1:8781/experience-console`이며 `Start-Local-Demo.cmd`, `Connect-Local-Console.cmd`로 연결한다. 앱 내 상황실에서 별도로 동의해 게시한 상태·항목 이름만 전송하며 의료 내용은 전송하지 않는다.

앱은 홈 또는 에뮬레이터 홈으로, 서버는 `Stop-Local-Demo.cmd`, 에뮬레이터는 창의 X로 종료한다. 저장한 가상 프로필과 PIN은 시연 도구 → 의료정보 잠금 → 저장 의료정보 삭제·잠금 초기화에서 함께 지울 수 있다. 차량 자체의 화면 잠금은 변경하지 않는다.

실패 시연은 도구의 다음 연결 실패 → 다시 시도, 가상 위치 해제 → 다시 확인, 카드 전체 철회, 추가 제한 → 상세 잠김, 앱 전환 → 의료정보 재인증 순서로 진행한다. 실제 OS 제한이 항상 우선한다.
