# LifeLink 119 v0.9 밝은 UI

시연 앱의 기존 짙은 배경과 형광 청록색은 SDK의 고정 디자인이 아니라 앱에서 직접 정한 색상입니다. v0.9는 밝은 회색 배경, 흰색 카드, 짙은 글씨, 차분한 파란색 행동 버튼을 사용하고 홈의 119 요청만 붉게 강조합니다. 제목·설명을 분리한 카드를 적용하고, 상담과 112·가족정보의 경로는 유지합니다. 응급 매뉴얼·진단 등 기존 화면도 같은 기본 색상을 사용합니다.

이는 원격 웹페이지나 브라우저가 아니라 Android의 기본 View로 만든 화면입니다. 기존 앱의 차량 UX 제한, 의료정보 잠금, 모든 외부 연결의 모의 시연 경계는 동일합니다. 119·112·109 신고·상담, 영상통화, 실제 출동은 일어나지 않습니다.

## 확인 방법

- v0.9 홈과 상담·긴급·영상 안내의 설치 APK 화면: 로컬 `verification/v09/ux/after/`.
- 빌드·Android 단위 테스트 143개·lint 성공: `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug`, 로컬 `verification/v09/build.log`.
- 에뮬레이터 주요 흐름 7개 묶음 통과: `python scripts/smoke-ux-v09.py --serial emulator-5580`, 결과 `verification/v09/ux/smoke-results.json`. 기존 응급 매뉴얼의 진입과 화면도 별도 확인했습니다.
- 테스트에서 520dp는 앱 내 레이아웃 미리보기입니다. 실제 차량, 모든 화면 크기, TalkBack 사용자 사용성 또는 상용 인증 검증은 아닙니다.
- 주요 색 조합의 계산된 명암비: 파란 버튼의 흰 글씨 7.34:1, 붉은 긴급 카드의 흰 글씨 6.65:1, 일반 글씨/흰색 15.24:1. 전체 화면과 모든 상태에 대한 접근성 인증을 뜻하지 않습니다.

APK와 로컬 검증 캡처는 Git 관리 대상이 아닙니다. 새 PC에서는 프로젝트 문서에 따라 직접 빌드합니다.
