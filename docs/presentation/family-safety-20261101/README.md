# LifeLink 119 · 나와 내 가족의 안전을 위한 자동차

현재 v0.7.0-demo의 이용 흐름을 설명하는 10장 자료입니다. 긴급 상황과 상담을 중심으로 구성했습니다.

- `LifeLink119_Family_Safety_Flow.pptx`: 편집 가능한 본문·흐름 도식과 장별 발표 메모를 포함합니다.
- `LifeLink119_Family_Safety_Flow.html`: 브라우저에서 바로 엽니다. 이전·다음 또는 방향키로 이동하고, F로 전체 화면을 전환합니다. 인터넷 연결이 필요하지 않습니다.
- `LifeLink119_Family_Safety_Flow.pdf`: 열람·공유용입니다.
- `LifeLink119_Family_Safety_Speaker_Notes.md`: 장별 설명 문안입니다.

긴급 요청과 의료정보 인증은 분리합니다. 가족정보는 인증 후 선택적으로 공유하고 철회할 수 있습니다. 모든 기관 연결·상담·출동·차량 표시 연계는 공모전용 모의 시연입니다. 실제 상담 음성이나 위험 자동 판단을 구현한 것처럼 표현하지 않았습니다.

표지는 AI로 생성한 서비스 콘셉트 이미지이며, 기능 화면은 실제 설치 APK의 공개 화면을 사용했습니다. 기존 소개 자료와 서비스 소스코드는 변경하지 않았습니다.
