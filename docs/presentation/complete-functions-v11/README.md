# LifeLink 119 전체 기능 발표자료 · v0.11

전체 기능을 화면별로 소개하는 41장 자료다. 최종 파일은 `output/`에 있다.

| 파일 | 용도 |
|---|---|
| `LifeLink119_전체기능_UI_소개_v11.pptx` | 발표·본문 편집. 실제 UI는 이미지다. |
| `LifeLink119_전체기능_UI_소개_v11.pdf` | 41장 열람본. 슬라이드를 이미지로 구성했다. |
| `LifeLink119_전체기능_UI_소개_v11.html` | 내려받아 브라우저에서 열기. 인터넷·서버 없이 이전·다음·방향키·전체 화면으로 조작한다. |
| `LifeLink119_전체기능_발표메모_v11.md` | 장별 설명과 구현 근거 |
| `LifeLink119_실제_UI_화면모음_v11.zip` | 실제 UI 원본 30개와 SHA-256 목록 |

## 화면의 근거와 한계

- 실제 화면 30개는 전용 Pleos 에뮬레이터에 설치된 v0.11 APK에서 캡처했다. 해당 APK SHA-256은 `51d5bec8061983321ddd80d132e072da78eca849aa7d7ca1331b6bc63bf04545`다. 새로운 빌드는 서명·환경에 따라 해시가 달라질 수 있다.
- 보호 화면 7개는 `FLAG_SECURE`를 유지하며 캡처하지 않았다. 현재 소스에 근거한 설명용 도식으로 표시했다.
- 주변 차량 협력의 승인·표시 후반 2단계도 캡처하지 못해 별도 도식으로 표시했다.
- 표지의 가족·자동차 그림은 콘셉트 이미지다. 실제 현장·사용자 사진이 아니다.
- 기관 연결·영상통화·위치 전송·차량 등화·건강정보 고속도로는 모의 연계다. 자료는 실차 적용·기관 승인·의료정보 실시간 조회를 증명하지 않는다.

## 제작 소스

`.build/build.mjs`, `finalize.mjs`, `supplement.py`, `verify-html.mjs`와 원본 입력 이미지·`screens/`를 보관한다. 렌더된 중간 이미지, 초안, 외부 런타임의 `node_modules`, 로컬 검증 로그는 Git에서 제외한다. 최종 결과는 일반 브라우저·PDF 뷰어·PowerPoint로 볼 수 있어 제작 도구가 필요하지 않다.

재생성에는 `@oai/artifact-tool`을 제공하는 Codex 런타임, Presentations 스킬의 검증 도구, Node.js, PyMuPDF가 필요하다. 이는 Android 앱 빌드 의존성과 별개다. 프로젝트 루트에서 실행하며, 검증 스크립트의 스킬·Python 경로는 해당 PC 환경에 맞춘다. `.build/node_modules`의 외부 도구를 저장소에 복사하지 않는다.

`capture_screens.py`는 ADB와 프로젝트의 native UI 검증 도구를 사용한다. 전용 테스트 AVD 이름·serial과 APK 버전을 확인한 뒤 실행해야 한다. 화면 보호를 해제하거나 실제 개인정보를 입력해 캡처하지 않는다.

검증 범위: PPTX 구조·레이아웃·재임포트, 41개 PDF 페이지, HTML 페이지 이동, 화면 ZIP CRC. 실제 PowerPoint 앱의 모든 환경에서 동일한 렌더링을 보증하는 검사는 아니다.
