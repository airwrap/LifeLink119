## 우선순위 및 수락 기준

1. **로컬 모의 상담센터**: localhost 서버, 브라우저 상담원/탑승자 화면, 5개 시나리오, 가상 상황 선택, 기본 OFF 동의, 세션 생성·접수·검토·안내·종료. 외부 기관에 요청하지 않음.
2. **Android 연동**: debug 빌드에서만 localhost 포트에 접속. ADB reverse로 로컬 서버에 연결. 전송은 고정 가짜 데이터만, 명시적 공유, 재시도·중복 생성 방지·상태 새로고침·연결 실패 안내.
3. **차량 특화 시연**: 합성 영상 예시·가짜 격자 위치·가상 경로. 정차/주행 UX 제한을 명시적인 시뮬레이션으로 구현. 실제 속도 감지와 혼동하지 않음.
4. **공식 SDK 확장**: 문서와 배포 public API가 확인된 배터리 충전율 읽기만 추가. 실제 차량 진단 결과는 모의 상담 payload와 분리. 미확인 카메라·Gear API·기관 통신은 추가하지 않음.
5. **자가 점검**: 서버 계약·오류·동의·상태 전이·용량/만료·idempotency 테스트, Android build/unit test, debug/release 권한 비교, 브라우저와 Pleos AVD 실제 흐름 확인. 발견한 문제를 수정하고 재검증.
6. **인계**: README/개발현황/테스트 보고서/실행·종료 스크립트/새 PC용 ZIP 갱신. 원본 ZIP과 이전 압축본 보존.
