원본 확대

개선 전은 Pleos API 34, 개선 후는 표준 Android 34 검증용 AVD에서 실행한 실제 앱 View 캡처입니다. Pleos 시스템의 부팅·차량 오디오 서비스 오류로 개선 후의 차량 플랫폼 검증은 완료하지 못했습니다. 같은 APK의 기존 비차량 모의 모드를 사용했으며 차량 제한을 해제하지 않았습니다. 플랫폼 차이는 UI 레이아웃 비교와 구분해 봐 주세요. 의료정보와 PIN 화면은 포함하지 않았습니다. 기관 연결·영상 안내는 앱의 모의 기능입니다.

검증: Android 단위 테스트 148개, lint 오류 0·경고 0, 네이티브 주요 동작 8항목. 앱 내부의 520dp 미리보기·큰 글씨도 확인했습니다. 실제 CarUX 콜백·차량 SDK·실차·상황실·오디오 출력·사람이 수행하는 스크린리더 검증은 포함하지 않습니다.

  • 112 emergency and 109 counseling remain reachable

  • Medical authentication stays protected; no PIN entered, no private frame captured
  • Additional driving restriction leaves quick119 available and video disabled

  • Large text and 520dp preview retain unclipped centered buttons; preferences restored
