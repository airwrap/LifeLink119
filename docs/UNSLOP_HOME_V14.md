# 동등한 네 가지 도움 · 홈 UI v0.14

## 방향

- 제품: 나와 가족을 위한 차량 응급지원
- 인상: 차분함, 균형, 명료함
- 환경: 큰 터치 영역으로 선택하는 차량 조작판
- 핵심 장면: 구조·구급, 의료·심리상담, 경찰 신고, 가족 안심콜을 같은 비중으로 표시
- 일관된 표시: 기관 번호의 작은 글자에만 119 빨강·112 파랑 사용

사용자가 지적한 문제는 두 긴급 카드의 큰 채움색과 큰 숫자가 나머지 두 기능보다 강하게 보인다는 점이다. [unslop](https://github.com/heydamir/unslop)의 polish mode를 적용해 홈의 시각적 비중만 조정했다.

## 변경

1. 간격: 기존 24dp 간격·가변 크기·큰 터치 영역 유지
2. 색상: 네 카드 모두 같은 흰 바탕·얇은 테두리·진한 제목 사용. 작은 기관 번호에만 의미 색 적용
3. 아이콘: 장식 아이콘 추가 없음
4. 문구: 기능명을 제목으로 통일하고 기관·용도를 보조 문구로 표시
5. 글씨: 네 제목의 크기·굵기 통일. 숫자만 큰 기존 64sp 표현 제거
6. 구성: 기존 네 기능의 순서·2열/짧은 가로형/좁은 화면 배치 유지
7. 세부: 중앙 정렬·포커스·누름·비활성 상태 유지
8. 시각 자료: 실제 Android 화면으로 확인
9. 움직임: 기존 상태 전환 유지, 새 애니메이션 없음

| 제목 | 보조 문구 | 기존 동작 |
|---|---|---|
| 구조·구급 | 119 긴급 요청 | 주행 중 위급상황 모의 요청 |
| 의료·심리상담 | 119 · 109 상담 | 의료상담·심리상담 선택 |
| 경찰 신고 | 112 긴급신고 | 112 모의 요청 |
| 가족 안심콜 | 119 · 가족 건강정보 | 인증 후 건강정보 등록·조회 |

안심콜은 현재 로컬 건강정보 화면으로 이어진다. 119 안심콜 외부 시스템의 실제 연결을 새로 구현하거나 연결된 것으로 바꾸지 않았다. 의료정보 인증·암호화·화면 보호, 실제 플랫폼 제한, 공통 모의 연결 안내를 유지한다.
