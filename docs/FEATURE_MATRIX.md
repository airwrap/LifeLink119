# 전체 기능 매트릭스 · v0.6

> 현재 v0.11 추가·변경은 [현재 구성](PROJECT_STATUS_V11.md)을 참조하세요. [주행 중 긴급 호출 D01](DRIVING_EMERGENCY_DEMO.md)을 포함해 총 19개이며, 아래 v0.6 기록은 당시 범위를 나타냅니다. 본인 건강정보 입력은 v0.10부터 별도 암호화 저장소에서 지원합니다.

`REAL`: 앱 자체에서 실제 수행하거나 확인된 SDK 읽기. `MOCK`: 실제 서비스 대신 고정 가상정보와 상태 전이를 체험. `NOT_AVAILABLE`: 이 빌드에서 실제 API 미연결. `NEEDS_PARTNERSHIP`: 기관/OEM 권한·협약·심사 필요. 외부 서비스에 대한 REAL 표시는 없다.

선택 인물의 접근성 및 실제 플랫폼 제한에 따라 우선순위가 바뀐다. 이 표는 fixture 기준이며 의료 판단 결과가 아니다. 모든 시나리오는 미등록 승객으로도 실행 가능하다.

공모전의 A~M 모의 동작과 신규 협력 흐름은 차량·PC 서버 없이 앱 안에서 진행할 수 있다. PC 메타데이터 게시와 공식 Virtual Console 가상 차량 입력은 별도 선택 도구다. 실제 검증 결과와 화면 근거는 [공모전 체크리스트](CONTEST_DEMO_CHECKLIST.md) 및 [구현 보고서](IMPLEMENTATION_REPORT.md)를 참조한다.
