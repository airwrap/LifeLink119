# 통합 확장 실행 계획

기존 Views와 단일 Activity를 유지하며 현재 core/data/vehicle 계층을 확장한다. 기존 정상 기능은 더보기의 시연 도구에서 접근하도록 보존한다.

1. Phase 0: 소스·SDK 감사, 원본 백업, 빌드·단위 기준선.
2. Phase 1: 홈 CTA 2개, 119/112 긴급 및 119/109 상담 선택, 공통 탐색.
3. Phase 2: 18개 fixture, 가상 가족·접근성·항목 동의, 단일 세션 엔진과 최대 3개 행동 규칙.
4. Phase 3: 앱 내 오프라인 상황실, 문자·수어·영상·위치·112·내비·안심콜·요약 상태 동기화, 기존 PC 상황실에 선택적 시연 상태 게시.
5. Phase 4: 기존 실제 SDK 진단 유지, 실제 CarUxRestrictions 구독, V2L·가상 디지털키와 실패 복구.
6. Phase 5: 단위·계약·UI 대표 흐름 검증, APK·설치본 대조, 기능 매트릭스·UX 사양·시연 대본·SDK 공백·최종 보고서.

프로필 입력은 실제 개인정보를 받지 않는 가상 fixture 편집으로 제한한다. 새 시연은 네트워크 없이 종료까지 동작하며, 기존 localhost 기능은 선택적으로 유지한다. 실제 SDK 연동과 Mock의 상태를 문서 및 시연 도구에 구분한다.

2026-10-28 실행 결과: Phase 0~4 구현 및 Phase 5 빌드·단위·서버·대표 네이티브 검사·문서 완료. 세로/좁은 창·TalkBack 전체·실차 주행 전환·기존 협력 전체 네이티브 E2E는 남은 검증으로 분리했다. [현재 보고서](IMPLEMENTATION_REPORT.md) 참조.
