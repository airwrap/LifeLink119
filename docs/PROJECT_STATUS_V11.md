## 이번에 다시 실행한 검사

- `Build-And-Test.cmd`: Android debug APK 빌드와 JVM 단위 테스트 성공. XML 보고서 기준 148개, 실패·오류·건너뜀 0개.
- `python -m unittest discover -s console -p 'test_*.py' -v`: 68개 성공.
- `python scripts/validate-demo-contract.py`: 성공.
- `:app:lintDebug`: 성공. lint 보고서 오류·경고 0개.
- 공유 대상에서 검사한 키·토큰 형식과 제외 파일 종류가 검출되지 않았고, 발표자료 ZIP·PPTX의 압축 무결성이 통과했다. 이는 모든 보안 취약점의 부재를 보증하는 검사는 아니다.

에뮬레이터 UI·시스템 인증·실차 시험은 이번 업로드 정리에서 새로 수행하지 않았다. 과거 화면 검증 결과와 현재 빌드·테스트 결과를 구분한다. 빌드에는 Android SDK 메타데이터 버전 및 기존 상태 표시줄 API의 사용 중단 경고가 있다.

## 다른 PC와 공동작업

1. 비공개 저장소의 공동작업자 초대를 수락하고 자신의 GitHub 계정으로 복제한다.
2. [새 PC 실행 가이드](OTHER_PC_GUIDE.md)에 따라 Python 또는 Android 개발환경을 준비한다.
3. [협업 규칙](../CONTRIBUTING.md)에 따라 기능 브랜치와 Pull Request로 변경을 합친다.

Git에는 소스·테스트·문서·발표자료·제작 입력과 스크립트를 포함한다. APK·서명키·SDK/JDK/AVD·`local.properties`·외부 `node_modules`·가상환경·로컬 검증 로그·발표자료 중간 렌더 캐시는 각 PC에 보관한다. 최종 발표자료를 보는 데 제작 도구는 필요하지 않다.
