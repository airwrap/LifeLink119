# 시연 경계 및 검증 · v0.4.1

## 구현에서 지킬 조건

- 모든 화면에 실제 신고·상담이 아니라는 고지 유지.
- 119/112/109 실제 발신, SMS, 외부 기관 HTTP 요청 없음.
- 촬영·마이크·GPS 권한 없음. 합성 영상/가짜 격자는 실제 데이터로 표현하지 않음.
- 증상·전화번호·VIN·실제 좌표·외부 URL·자유 입력을 받지 않음.
- 차량·위치·합성 영상 선택은 기본 OFF, 로컬 전송도 별도 버튼으로 명시.
- 의료·이송·병원·경찰 호송 결정을 자동화하지 않음.
- 이동 상태는 수동 시연 문맥이며 응급지원 접근을 잠그지 않음. 실제 속도/기어 감지나 실차 안전 인증은 미구현.

## v0.3 응급 매뉴얼·표시 승인 추가 점검

- 매뉴얼의 출처·확인일·대상·의료진 검토 전 표시, 119 신고 우선, 성인/영유아 구분을 확인합니다.
- 승인 전 시작, 109 승인, 다른 세션 승인, 기관 변경, 탑승자 확인·승인을 거부해야 합니다.
- 재전송으로 승인이 연장되지 않고 120초 만료·철회·종료 시 표시가 중단되어야 합니다.
- 연결 실패·8초 경과·백그라운드에서 화면 표시를 중단해야 합니다. 이동 상태 선택은 중단 조건이 아닙니다.
- 실제 차량 권한·제동등 제어·기관 연결을 추가하지 않았는지 확인합니다. 실제 차량·등화 승인·의료진 검토는 미완료입니다.

자동 갱신과 화면 이동이 겹칠 때 버튼이 비활성 상태로 남는 문제를 대기열 처리로 수정했습니다. 다중 창에서는 다른 앱이 활성화되어도 기존 Activity가 resumed 상태로 남을 수 있어 API 29 이상은 top-resumed 콜백으로 표시를 잠그고 API 28은 pause/resume을 사용합니다. 잠금 화면에 표시가 없는데도 watchdog이 반복 갱신하던 상태도 수정했습니다. [Android 공식 설명](https://developer.android.com/about/versions/10/behavior-changes-10#resumed)을 참고했습니다.

기본 uiautomator CLI의 idle 대기는 지속 점멸 화면에서 멈출 수 있어, 별도 검증 APK의 공개 접근성 API로 화면을 읽고 버튼을 작동시켰습니다. 앱 애니메이션은 유지했으며 검증 APK는 제거했습니다. 연결 실패는 HTTP keep-alive에 영향받는 ADB reverse 제거 대신, 소유권을 확인한 프로젝트 서버의 일시 정지로 실제 read timeout을 유도했습니다. 최대 30초·부모 프로세스 종료 시 자동 복구하며 최종 서버는 지연 0으로 복원했습니다.
