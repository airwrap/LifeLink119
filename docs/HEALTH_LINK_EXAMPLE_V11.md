# 건강정보 고속도로 가입 동의 예시 · v0.11

홈 → 우리 가족 안심콜 → 인증 → 건강정보 고속도로 가입·연결에서 동의를 선택하면 고정된 가상 투약 내역을 볼 수 있다. 예시 화면에서는 동의 철회와 돌아가기를 제공한다. 동의하지 않으면 예시가 열리지 않고, 화면을 떠나거나 앱이 백그라운드로 가거나 의료정보 인증이 잠기면 예시 동의는 초기화된다.

**실제 가입, 본인 확인 요청, 의료정보 조회 또는 전송은 없다.** 예시 약품과 날짜는 고정된 가상 데이터이며 개인의 처방 기록이 아니다. 앱에 직접 입력한 건강정보는 기존 암호화 보관소에 남고 예시와 섞이거나 자동 공유되지 않는다. 실제 119 안심콜도 연결되지 않았다.

의료정보 보호와 기존 차량 UX 제한은 그대로 적용한다. 의료정보 화면의 캡처 방지를 해제하지 않는다. 에뮬레이터 시험에는 임시 PIN과 가상 입력만 쓴다.

빌드: `:app:assembleDebug :app:testDebugUnitTest`. 에뮬레이터 검증: `python scripts/smoke-health-link-v11.py`. 결과 파일은 로컬 `verification/v11/health-link.json`이다.

최종 APK에서 Android 단위 테스트 148개와 lint가 통과했다. 에뮬레이터에서 동의 전 차단, 동의 후 가상 내역, 동의 철회, 앱 전환 후 동의 초기화와 재인증, 직접 입력 기록과의 분리 및 기존 긴급 요청을 확인했다. 개인정보 화면은 보호된 상태로 검증했으며 실제 기관 연결이나 실차 시험은 하지 않았다.
