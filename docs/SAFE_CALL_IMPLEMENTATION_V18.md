# 가족 안심콜 기능 · v0.18

기준일: 2026-11-08. APK `0.18.0-demo`, versionCode 20.

## 실제로 사용할 수 있는 앱 기능

- `가족 안심콜`에서 인증 후 본인과 가족의 이름·병력·알레르기·투약 내역을 기기에 저장·조회·수정·삭제한다. 최대 12개 레코드이며 한 명을 삭제해도 다른 사람의 정보는 유지한다.
- 정보별로 수혜자 본인/가족·대리자 관리 방식, 안심콜 등록 연락처, 등록 여부에 대한 사용자 확인, 마지막 수정 시각을 기록한다. 대리 관리에는 동의·권한이 있다는 사용자의 확인이 필요하다. **공식 대리 권한을 기관에서 검증하는 기능은 아니다.**
- 연락처와 건강정보는 Android Keystore AES-GCM으로 암호화한다. 조회 화면에는 연락처 끝 네 자리만 표시한다. 이전 단일 본인 레코드는 계속 읽을 수 있으며, 정상 저장할 때 새 암호화 목록으로 옮긴다. 읽기 실패 시 기존 암호문을 덮어쓰지 않는다.
- 이름·등록 연락처·관리 방식이 바뀌면 기존의 등록 완료 확인 체크를 해제한다. 저장 여부와 공식 등록 여부는 별개다.
- 홈 복귀·앱 전환·인증 만료 시 의료정보 잠금을 유지한다. 편집 대상 ID와 입력 내용을 saved-instance state에 별도 저장하지 않는다. 민감 화면의 캡처 보호를 해제하지 않는다.

등록 여부는 ‘확인 안 됨’ 또는 ‘등록 완료 · 사용자 확인’이다. **‘공식 확인 완료’ 상태는 제공하지 않는다.** 앱에서 병력이나 연락처를 수정해도 공식 안심콜의 정보가 자동 수정되지는 않는다.

## 공식 사이트 연결

`더보기 → 119안심콜 공식 가입·수정` 또는 `가족 안심콜 → 119안심콜 가입·등록 안내`에서 수혜자 본인/대리자 절차를 확인할 수 있다.

- 119안심콜 공식 가입·수정 사이트, 소방청 이용 안내, 건강정보 고속도로 공식 안내를 외부 브라우저로 연다.
- 고정된 공개 HTTPS URL만 전달한다. 이름·전화번호·병력·등록자 역할은 URL이나 Intent 부가정보에 첨부하지 않는다.
- 브라우저가 없으면 휴대전화·PC에서 사용할 공식 주소를 안내한다.
- 사이트를 방문하거나 앱으로 돌아왔다는 이유로 가입 완료를 자동 기록하지 않는다.
- 공개 안내에는 의료정보 PIN을 요구하지 않는다. 실제 CarUX 상세 조작 제한이 적용되면 브라우저 이동과 상세 안내는 제한한다.

이것은 **공식 안내·가입 화면으로 이동하는 연결**이다. 기관 등록·조회 API나 실제 119 상황실 의료정보 제공 연계가 완료된 것은 아니다. 현재 기관 승인·명세·테스트 계정이 없으므로 그 부분은 [실제 기관 연계 전환 준비](AGENCY_LINKAGE_HANDOFF.md)에 정리했다.

## 긴급 연결 안의 대상·회선 대조

`119 요청 → 추가 지원 → 119안심콜 모형`에서 확인한다. 주행 중 긴급 요청은 등록·의료정보 인증·조회 완료를 기다리지 않는다. 상세 대조 화면은 기존 인증과 실제 플랫폼 제한을 따른다.

1. 도움 대상자는 가상 가족 예시에서 선택한다. 대상 미선택은 ‘미등록’으로 처리하지 않는다.
2. 수혜자 본인/가족·대리자를 구분하고 대리자는 관리 권한을 확인한다.
3. 가상 회선으로 등록한 전화/다른 가족 전화/차량 회선/확인 불가/공용 전화를 선택한다.
4. 이번 등록정보 확인에 동의한 뒤 대조한다. 일치·불일치·확인 불가·복수 후보·예시 정보 없음이 구분된다.
5. 시간 초과·조회 오류·기관 연계 미지원의 응답도 확인할 수 있다. 오류를 ‘미등록’으로 표시하지 않는다.
6. 동의 철회, 대상/회선/역할/상황 변경, 잠금·앱 전환·플랫폼 제한·세션 종료에서 결과 또는 진행 중 요청을 무효화한다. 늦은 응답이 이전 결과를 되살리지 못한다.

**대조는 가상 회선·가상 가족 예시로 수행한다.** 실제 Bluetooth 휴대전화·SIM·차량 eSIM의 발신번호를 읽거나 검증하지 않는다. 기기에 직접 입력한 가족의 실제 연락처·건강정보를 대조 모형이나 PC 상황실로 넘기지 않는다.

번호가 다르거나 확인되지 않아도 연결을 유지한다. 상황요원에게 신고자와 도움 대상자가 다를 수 있음을 알리는 안내를 제공하며, 번호를 맞추기 위해 자동 종료·재발신하지 않는다. 번호 일치가 의료정보 공유 동의를 대신하지 않는다.

## 코드와 검증

- `core/SafeCallLink.kt`: 역할·회선·대조 상태, 동의, 세대별 요청 무효화, 공식 공개 URL 목록.
- `core/Experience.kt`: 인증·실제 플랫폼 제한과 세션 생명주기 연결.
- `data/PersonalHealthRecord.kt`: 암호화 가족 목록과 이전 단일 레코드 읽기 호환.
- `data/OfficialHealthNavigation.kt`: 공개 URL만 전달하는 외부 브라우저 이동.
- `ui/ExpansionUi.kt`: 기존 96dp 터치 영역과 밝은 버튼을 유지한 관리·안내·대조 화면.
- `scripts/verify-safe-call-v18.py`: 가상 입력으로 검사하며 기존 PIN·의료정보·사용자 편집 프로필이 있으면 중단한다. 테스트 PIN을 로그에 남기지 않고 테스트가 만든 정보만 정리한다.

## 이번 단계에 포함하지 않은 기능

- 실제 신고 회선·SIM·Bluetooth 번호의 확인, 기관의 공식 등록/조회 API, 실제 의료정보 제공.
- 기관이 확인하는 대리 권한 인증. 현재 권한 체크와 등록 완료 체크는 사용자 진술이다.
- 의료기관의 투약 이력 자동 조회, 현재 복용/과거 투약의 자동 판별. 현재 투약 내역은 직접 입력이다.
- 동반 휴대전화 앱/웹 가입 양식과 정부 가입 양식 자동 제출.

최초 검토의 20개 인수 기준 전체가 상용 서비스 수준으로 완료된 것은 아니다. 위 검증은 이 문서에서 명시한 기기 내부 기능과 가상 조건, 공식 공개 사이트 이동 범위다.

기존 표준 Android AVD뿐 아니라 새 시험 AVD의 첫 부팅에서도 Android System UI 응답 없음 창이 관찰되었다. 앱의 단위 검사와 구분하며, 해당 시스템 창을 닫은 뒤 실제 조작 결과를 별도 기록한다. 실제 차량·실제 119 통화·기관 환자정보 조회·법적 대리 권한 검증은 이 검증 범위에 포함되지 않는다.
