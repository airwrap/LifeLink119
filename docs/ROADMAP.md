# 개발 단계 및 수락 기준 · v0.3

## v0.3 추가

- [x] 공식자료 출처·확인일·대상·주의사항을 표시하는 기본 응급상황 매뉴얼 6개 항목과 Android 오프라인 열람.
- [x] 119 또는 112 역할의 비상 확인·한시 승인·철회·만료를 거치는 화면 표시 시연.
- [x] 실제 기관 인증과 차량 등화를 연결하지 않고 제동등 읽기/쓰기 권한을 추가하지 않음.
- [ ] 의료 전문가의 매뉴얼 검토·승인과 대상별 상세 지침 확장.
- [ ] 표시등에 관한 관계기관·제조사·안전기준 검토와 정식 승인·인증 연동. 현재는 도로에서 사용할 수 있는 차량 기능이 아님.

구현과 법령·의료 자료 검토 근거는 [상세 안내](EMERGENCY_MANUAL_AND_SIGNAL.md)에 기록합니다.

사용자 후속 요청에 따라 설계로 남아 있던 로컬 상담센터를 구현하고 앱까지 연결했습니다. 작업계획과 결과는 WORK_PLAN_V02.md, IMPLEMENTATION_REPORT_V02.md를 참조하세요.
