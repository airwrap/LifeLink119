# 기본 응급상황 매뉴얼과 기관 승인형 비상 표시 · v0.3

## 반영한 목적

가족 동승 상황에서 기본 행동을 확인할 수 있도록 **앱 안에서 읽는 매뉴얼**을 추가했습니다. 주변 차량에 비상상황을 알리는 표시등은 **119 또는 112가 상황을 확인하고 승인한 경우에만 사용한다**는 사용자 조건을 설계에 반영했습니다.

현재 구현한 것은 학습용 매뉴얼과 **화면 안의 표시등·기관 역할 시연**입니다. 실제 기관의 신원·승인을 검증하거나 차량 제동등·비상등·외부 경광등을 켜는 기능은 없습니다. 실차용 승인 기능으로 사용할 수 없습니다.

## 기본 매뉴얼

- 먼저 할 일과 119 신고, 성인 CPR, 성인 AED, 심한 외부 출혈, 열에 의한 화상, 경련의 6개 항목입니다.
- 단일 원본은 `app/src/main/assets/emergency-manual.json`입니다. Android APK에 포함해 인터넷 없이 읽으며 웹 `/manual`도 같은 원본을 사용합니다.
- 모든 카드에 적용 대상, 행동 순서, 주의사항, 출처와 확인일 **2026-10-25**를 표시합니다.
- 공식자료를 요약한 **의료진 검토 전 학습용 콘텐츠**입니다. AI 진단·증상 평가·위험도 분류·약물 용량 안내는 추가하지 않았습니다. 실제 119 지시가 우선합니다.
- CPR 카드는 성인 기준입니다. 영유아·소아·임신부·익수 등의 처치가 같다고 안내하지 않습니다. 2025년 지침에서 영아 술기가 변경되었으므로 과거 영아 설명을 재사용하지 않았습니다.
- 현재 앱은 실제 신고 통화를 연결하지 않습니다. 앱의 시연 절차나 표시 승인을 기다리느라 실제 신고를 늦추면 안 됩니다.

### 의료 자료

1. [질병관리청 국가건강정보포털: 심폐소생술](https://health.kdca.go.kr/healthinfo/biz/health/gnrlzHealthInfo/gnrlzHealthInfo/gnrlzHealthInfoView.do?cntnts_sn=6226): 현장 안전, 신고, **성인** CPR과 AED 부분 확인.
2. [질병관리청 2026-01-29 개정 발표](https://www.kdca.go.kr/kdca/2847/subview.do?enc=Zm5jdDF8QEB8JTJGYmJzJTJGa2RjYSUyRjQxJTJGMzA5OTA2JTJGYXJ0Y2xWaWV3LmRvJTNG): 2025년 한국 심폐소생술 가이드라인의 성인 CPR 유지, 영아 술기 변경 등 확인.
3. [AHA·American Red Cross 2024 First Aid Guidelines](https://cpr.heart.org/en/resuscitation-science/2024-first-aid-guidelines): 기본 안전, 직접 압박 지혈, 열화상 냉각, 경련 중 부상 예방 부분 확인. 한국어 앱에서는 응급의료 도움 요청을 119로 표기합니다.

원문 도표·사진·전체 매뉴얼은 재배포하지 않았습니다. E-GEN 원문은 이번 조회에서 접속 오류가 있어 본문을 확인한 근거로 사용하지 않았습니다. 공개 운영 전 응급의료 전문가의 대상별 검토와 문구 승인이 필요합니다.

## 표시 승인 시연 순서

1. 탑승자가 로컬 모의 상담 세션에서 **표시 승인 요청**을 누릅니다. 기본값은 OFF입니다.
2. 상담원 웹에서 접수와 검토 단계까지 진행합니다.
3. 상담원 역할 화면에서 **119 또는 112 역할**을 선택하고 **비상상황 확인 (모의)**을 누릅니다.
4. 같은 기관 역할로 **120초 표시 승인 (모의)**을 누릅니다. 확인과 승인은 별도 단계입니다.
5. 탑승자가 **승인된 화면 점멸 시작**을 눌러야 화면 표시를 시작합니다. 탑승자 화면에는 확인·승인 버튼이 없습니다.
6. 승인 만료, 기관 역할의 철회, 탑승자 중단, 공유 철회 또는 세션 종료 시 표시를 끕니다. 만료 후에는 새 요청과 확인·승인이 필요합니다.

모의 승인 ID는 `SIM-LIGHT-DEMO-...`이고 해당 세션에만 연결됩니다. 109 역할은 승인할 수 없습니다. 같은 승인 요청을 재전송해도 만료 시간이 연장되지 않습니다. **120초와 화면의 2초 점멸 주기는 시연용 선택이며 승인된 차량 등화 규격이 아닙니다.** 동작 줄이기를 설정한 브라우저와 Android의 애니메이션 비활성 환경에서는 깜빡임 없이 상태를 표시합니다.

앱·웹은 최근 서버 응답이 8초를 넘거나 연결 실패를 확인하면 화면 표시를 중단합니다. 백그라운드에서는 표시를 숨깁니다. v0.4.1부터 이동 상태 미선택·이동 중·정차 모두 승인된 화면 표시를 허용합니다. 이는 화면 동작에 대한 방어 로직이며 실차 안전 보증은 아닙니다.

Android 다중 창에서는 다른 앱으로 전환해도 기존 Activity가 resumed 상태로 남을 수 있어, API 29 이상은 `onTopResumedActivityChanged`로 활성 앱 여부를 확인합니다. 활성 앱에서 벗어나면 표시를 중단하고 복귀 시 최신 승인 상태를 다시 조회합니다. 정차 확인은 요구하지 않습니다. API 28은 `onResume`/`onPause`를 사용합니다. 근거: [Android 다중 resume 공식 안내](https://developer.android.com/about/versions/10/behavior-changes-10#resumed).

### API와 역할의 한계

- `POST /api/demo/sessions/{id}/signal/passenger`: REQUEST, ACTIVATE, STOP.
- `POST /api/demo/sessions/{id}/signal/operator`: CONFIRM, APPROVE, REJECT, REVOKE. `authority`는 문자열 `119` 또는 `112`만 허용합니다.
- 모든 요청은 `syntheticOnly:true`를 요구합니다. 응답의 `signalPreview.hardwareConnected`는 항상 `false`입니다.
- 서버는 **인증 없는 localhost 역할 연습 서버**입니다. URL의 역할 구분은 실제 기관 인증·권한 통제가 아닙니다. 운영용 승인에는 기관 인증, 서명된 한시 승인, 재전송 방지, 제조사 권한, 통신 단절 시 소등, 감사·오남용 대응을 별도로 구현해야 합니다.
- 차량 SDK는 기존 도어·배터리 **읽기**만 유지합니다. 새 차량 권한·등화 쓰기 API·실제 신고·전화·문자·외부 승인 호출은 추가하지 않았습니다.
