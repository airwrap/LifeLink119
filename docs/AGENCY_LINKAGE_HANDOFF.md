# 실제 기관 연계 전환 준비

기준일: 2026-11-08. 사용자가 기관 연계 승인·공식 API 문서·테스트 환경을 아직 보유하지 않았음을 확인했다. 현재 앱은 **공식 사이트 안내 연결 + 기기 내부 가족정보 관리 + 가상 회선 대조**까지 제공하며, 실제 기관 등록·조회·정보 제공은 하지 않는다.

## 지금 연결한 경로

| 기관/서비스 | 앱에서 제공하는 동작 | 전송 내용 |
| --- | --- | --- |
| 119안심콜 | 공식 가입·정보 수정 사이트를 외부 브라우저로 열기 | 고정 URL `https://u119.nfa.go.kr/`만 전달 |
| 소방청 | 공식 이용 안내 열기 | 고정 공개 안내 URL만 전달 |
| 건강정보 고속도로 | 공식 안내 사이트 열기 | 고정 URL `https://www.myhealthway.go.kr/`만 전달 |

이름·전화번호·병력·기기 ID·등록자 역할을 URL, Intent 부가정보, 요청 본문에 붙이지 않는다. 자동 로그인·자동 입력·가입 제출도 하지 않는다. 외부 사이트 방문 또는 앱 복귀를 가입 완료 증거로 처리하지 않는다. 브라우저가 없는 차량 환경은 휴대전화·PC에서 열 수 있는 공식 URL을 안내한다. 실제 CarUX 상세 조작 제한은 유지한다.

등록 절차는 [소방청 공개 안내](https://www.nfa.go.kr/nfa/safetyinfo/emergencyservice/urelaxcallservice/)와 [공식 안심콜 사이트](https://u119.nfa.go.kr/)를 따른다. 건강정보 고속도로는 [공식 API 소개](https://myhealthway.go.kr/portal/index?page=Individual%2FPortal%2FMediMyData%2FMydataApi)가 있지만, 공개 소개가 이 앱의 이용 자격·접근 권한이나 즉시 호출 가능한 테스트 계정을 뜻하지 않는다.

## 119안심콜 운영기관에 확인할 항목

1. 민간 차량 앱이 이용할 수 있는 등록·수정·조회 인터페이스 및 정식 참여 절차의 유무.
2. 공식 인터페이스 명세·버전·시험 URL·시험 자격증명 발급 방법. 화면을 분석해 비공개 가입/조회 엔드포인트를 추정하지 않는다.
3. 수혜자 본인과 대리자의 인증 방법, 위임·법정대리 관계 확인과 철회 처리.
4. 실제 신고 회선과 수혜자의 등록 전화가 다를 때 허용되는 식별 절차. 차량 eSIM/eCall, 공유 전화, 전화 없는 수혜자, 복수 수혜자 매핑 규칙.
5. 통신사의 실제 발신번호 확인 근거와 앱/OEM이 가진 통화 계정 정보의 신뢰 범위.
6. 해당 사건과 수혜자를 연결하는 방식, 조회 결과와 제공 내역의 유효 기간·만료·중복 방지.
7. 제공 가능한 항목과 최소 범위, 등록정보의 최종 갱신일·출처·모름/없음 구분.
8. 조회 실패·미발견·권한 오류·시간 초과의 구분, 상황실의 수동 확인 절차.
9. 누가 언제 어떤 사건에서 정보를 열람·제공했는지 기록하는 방법과 보관·삭제·사고 대응 책임.
10. 승인된 시험 환경과 종료 기준. 실제 긴급 번호에 시험 신고하거나 실환자 정보를 보내지 않는 검증 방식.

## OEM/휴대전화 통화 연계 담당자에게 확인할 항목

- Pleos 차량 앱이 사용할 수 있는 통화 계정 조회·선택·상태 콜백과 요구 권한. 현재 사용 중인 Vehicle SDK 도어·SoC·에어백 API와 별개다.
- Bluetooth HFP 휴대전화와 차량 회선의 구분, 여러 휴대전화·듀얼 SIM 사용 시 실제 발신 계정의 확인 방법.
- 번호를 읽을 수 없는 경우의 표현과 검증 근거. 앱이 읽은 번호나 사용자가 입력한 번호만으로 수혜자 신원을 확정하지 않는다.
- 회선 변경·연결 해제·사용자 전환 시 기존 조회와 동의를 무효화하는 이벤트 계약.
- 진행 중인 신고 통화를 끊거나 자동 재발신하지 않고 추가 정보를 전달하는 승인된 경로.

[AOSP HFP 설명](https://source.android.com/docs/automotive/ivi_connectivity#hands-free-profile)은 휴대전화별 통화 계정과 다중 기기 선택을 설명한다. 이를 Pleos에서 바로 쓸 수 있는 권한/SDK로 간주하지 않는다.

## 건강정보 고속도로 담당자에게 확인할 항목

- 참여 가능한 기관·사업자 요건과 신청/심사/시험 절차.
- 본인 인증, 항목·기관·기간별 동의, 전송 요구와 동의 철회 규격.
- 투약·병력 등 제공 항목의 정의, 출처·갱신일, 현재 복용과 과거 투약 이력을 구분하는 방법.
- 외부 기관에 재제공할 수 있는 범위와 사건별 안심콜 정보 제공의 별도 요건.
- 운영 자격증명의 보관 위치, 허용 네트워크·인증서 등 운영 환경. 자격증명은 APK·Git·로그에 넣지 않는다.

건강정보를 불러오는 동의는 안심콜 가입 완료 또는 119 제공 동의와 동일하지 않다.

## 준비된 문의 초안 — 발송하지 않음

> LifeLink 119는 차량 안의 긴급 요청과 상담, 가족 응급정보 확인을 지원하는 공모전용 Android PoC입니다. 현재 실제 긴급전화나 기관 의료정보 조회 없이 가상 데이터로 기능을 검증하고 있습니다. 수혜자·대리자 등록과 차량/휴대전화 신고 회선의 불일치를 정확히 처리하기 위해, 승인된 등록·조회 연계의 제공 여부와 참여 절차, 테스트 환경 및 수혜자 식별·동의·보안 요건을 확인하고자 합니다. 담당 부서 및 검토에 필요한 자료를 안내해 주시면 구현 범위와 데이터 흐름 자료를 제공하겠습니다.

## 전환 시 완료 조건

- 공식 명세와 승인된 테스트 계정이 확보된 범위만 구현한다.
- 현재의 `MOCK` 결과를 공식 응답으로 승격하지 않고 별도 어댑터와 응답 근거를 둔다.
- 대상/회선/권한/세션이 바뀐 뒤 늦게 온 응답은 폐기한다.
- 실패해도 긴급 요청은 유지하고, 조회 불가를 미등록으로 표시하지 않는다.
- 보호 화면·암호화 저장·개인정보 비노출 회귀 검증을 통과한다.
- 공식 시험 환경의 수신 확인 증거가 있어야 실제 연계 완료로 기록한다.
