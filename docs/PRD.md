# LifeLink 119 · 제품 요구사항 (PRD v0.1)

## V0.2 구현 현황

후속 구현 요청에 따른 현재 기능·제약은 [V0.2 구현 보고서](IMPLEMENTATION_REPORT_V02.md), [개발 현황](ROADMAP.md), 프로젝트 README를 확인하세요. 아래 v0.1 목적과 장기 협력 과제는 기획의 기준으로 보존합니다.

## 목적과 핵심 이야기

- 슬로건: **내 차가 우리 가족을 위한 응급지원 공간으로 바뀌는 순간**
- 플랫폼: 현대차·기아 Pleos Connect 차량용 Android 앱
- 핵심 가치: 이동 중에도 탑승자가 필요한 전문기관에 쉽게 도움을 요청하고, **동의를 거쳐** 차량·영상·위치정보를 전문인력과 공유할 수 있도록 한다.
- 주의: 정식 구급차의 의료 장비·자격·우선통행을 앱이 제공하는 것은 아니다.

## 이용 시나리오

1. **응급의료상담**: 동승자의 증상 발생 → 119 연결 → 상담원 응급처치 지도·구급차 필요성 판단
2. **사고 영상**: 동승자가 현장 상태 공유 요청 → 빌트인 캠/스마트폰 영상의 이용자 승인 → 119 다매체 신고 접수
3. **이송 협력**: 119에서 대응 판단 → 전문기관이 필요시 112 공동대응 검토 → 경찰이 지원 여부 결정
4. **심리위기**: 당사자가 도움 요청 → 109 전문상담 연결, 즉각적인 생명위험은 119/112 우선

## 범위 구분

### MVP (현재 폴더에 구현)
- 차량용 홈 + 5개 상황 화면 및 사용자 동작
- 사용자에게 **항상 시연임을 명확히 표시**하는 모의 상담 연결
- Pleos SDK 도어 데이터 연결 확인 진단
- SDK 의존성과 최소 권한 선언
- 안전한 데모 정책 단위 테스트

### V0.2 (다음 목표)
- 상담 전 정보입력(비식별/가상 데이터만), 명시적 동의 흐름, 모의 상담원 웹 화면
- 차량 정보·위치 동의 API 연동 (SDK 지원/권한 확인)
- 모델별 빌트인 캠 지원 상태 감지의 별도 기술타당성 조사
- NaviHelper 목적지/경유지 설정 시뮬레이션
- 이동 중 응급지원과 동승자·관제 역할의 UX 테스트

### 장기 협력 과제
- 119구급상황관리센터 및 다매체 신고 정식 연계
- 112 공동대응 공식 절차 연계, 경찰 에스코트 자동보장 기능은 금지
- 빌트인 캠 실시간 전송의 제조사 API 제공/승인
- 정보보안, 개인정보·의료정보 처리, 녹화 및 제3자 정보보호

## 평가 지표(제안)

- 데모 성공률: 앱 100% 실행 / 5개 시나리오 진입 성공
- SDK 진단: Pleos 전용 AVD에서 API 호출 성공 1개 이상
- 안전성: 모의버전에서 통화/데이터 전송 0건
- 실증 단계: 실제 통화 연결 지연, 상황정보 전달시간, 사용자 이해도, 상담사 사용성 (실증 허가 후 측정)

## 위험 및 대응

- 공공 긴급번호 오사용: 테스트앱은 외부 통화·전송 코드 금지
- 주행 중 주의 분산: 이동 중 응급지원 접근을 유지하고 상세 문답·영상조작은 동승자·관제 역할로 설계. 실차 속도 감지는 미연동
- 차량 API 가용성: SDK별 capability 조회, 앱은 폴백 UI 제공
- 자동판단 오인: 의료진단/우선통행/경찰출동 승인을 주장하지 않음
- 개인 정보: MVP는 저장·전송하지 않으며 이후 최소수집·동의·삭제정책 수립
