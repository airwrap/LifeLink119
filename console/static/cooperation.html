    3. 협력 차량 역할 · 자발적 수락과 현장 지원

    가까운 차량도 참여 동의·요청된 교육 조건을 충족해야 초대합니다. 임무 부여나 표시 승인을 기다리며 실제 119 신고·즉시 필요한 응급대응을 늦추는 절차가 아닙니다.

    기본 응급상황 매뉴얼 ↗

    요청자 역할

    인계까지가 하나의 임무

    요청 → 기관 확인 → 초대·수락 → 임무 부여 → 현장 지원 → 구급대 인계. 인계·철회·만료 시 표시를 종료합니다.

    환자 이송과 병원 선택은 이 PoC에서 승인하지 않습니다. 다음 실험 단계는 관계기관과 설계하는 마네킹·폐쇄 시험장 시나리오입니다.
